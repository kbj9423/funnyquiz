# 넌센스 퀴즈

초등학생용 넌센스 퀴즈를 하나씩 보여주는 웹페이지입니다. 휴대폰으로 보는 것을 기준으로 만들었습니다.

- 문제 카드를 터치하면 정답이 나옵니다. 다시 터치하면 정답이 가려집니다.
- '다음 문제'를 누르면 무작위로 다음 문제가 나옵니다. 모든 문제가 한 번씩 나오기 전에는 같은 문제가 다시 나오지 않습니다.
- '초성 힌트'를 누르면 정답의 초성(예: ㅇㅇㄱ)이 먼저 보입니다.
- '프린트용 30문제 뽑기'를 누르면 무작위 30문제를 A4 1장으로 인쇄합니다. 정답은 오른쪽 점선 너머에 있어서 접어서 가릴 수 있습니다.
- 오른쪽 위 버튼을 누르면 전체화면이 됩니다. 아이폰은 이 기능을 지원하지 않아서 버튼이 보이지 않습니다.

## 퀴즈 추가·수정

`quiz.xlsx`를 엑셀로 열어 고치면 됩니다.

- A열: 문제, B열: 정답 (첫 줄은 제목 줄이라 읽지 않음)
- 문제나 정답 중 하나라도 비어 있는 줄은 건너뜁니다.
- 인쇄할 때 한 줄에 들어가려면 문제는 30자 안쪽이 좋습니다.
- 파일 이름은 `quiz.xlsx` 그대로 두고, 저장한 뒤 사이트에 다시 올리면 반영됩니다.

## 참고

- `index.html`을 더블클릭해서 열면 엑셀 파일을 읽지 못합니다. 웹 주소로 열어야 합니다.
- '이미 나온 문제' 기록은 기기(브라우저)마다 따로 저장됩니다.
